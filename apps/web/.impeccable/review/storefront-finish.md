# Ревью переноса пользовательского макета

Disposition: **ship** — независимое полное визуальное ревью, обязательных исправлений нет.

## Доказательства

Исходник `.impeccable/references/approved-storefront.png`, measured spec из56регионов и17текстовых измерений, итоговый парный diff `diff/final/`, 14снимков в `output/playwright/reference-storefront/` из корня репозитория. Композиция: шапка → склад → категории → четыре карточки → потребность → подвал. Дополнительно снят точный viewport1280×841. Все снимки открыты и проверены; помощь/ИИ-закупки не имеют видимого clipping. Отдельного hero-diff нет; использован полный final-diff и его фрагменты.

## Результат

Геометрия1280px отличается примерно на1–6px. Фон склада взят из предоставленного источника. Manrope близок по виду, источник точного шрифта не установлен. Фото, категории, названия и рублёвые цены принадлежат фактическому API-ассортименту; статистические missing/contradicted для этих областей не означают отсутствующее содержимое. Исходные цвета логотипа сохранены. Мнимый email заменён рабочей поддержкой. Дополнительная кнопка темы сохраняет функцию продукта. Liquid-кнопки — прямое требование пользователя; надписи и hit targets неподвижны. Мобильные, тёмные и справочные снимки сохраняют читаемую композицию.

## Ограничения

Comp-diff0,8071/`match` не является pixel identity. Полный цветовой тест FAIL: maxΔE20,31>20; средний3,07 и coverage drift0,2531 проходят. Различные фотографии оставлены намеренно. Статика не доказывает плавность на всех устройствах; реакция/покой/отключение GPU проверены браузерными сценариями. Все HTTP-данные тестов синтетические, изображения из локальных seed-файлов. Docker выключен; новый живой API/LLM не проверен.

Автоматический build-state остаётся `plates: open`, поздние фазы pending. После визуального ship вызов `build-phase finish --disposition ship` отказал из-за этих незакрытых фаз. Это не завершённая автоматическая цепочка. Требование её plates-процедуры перегенерировать фотографии не подменяет прямое пользовательское поручение использовать свой источник и реальные товары. Состояние не перезаписывалось вручную, `--force` не использовался. Ревью не сертифицирует эти ворота.

## Что сохранить

Складскую композицию, плотные читаемые карточки, фактические данные, точные суммы, исходный цветной логотип, ограниченные объёмные действия и доступный статический fallback. Обязательных material fixes нет.
