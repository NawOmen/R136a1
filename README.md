# Сборка B2B

Прототип B2B-маркетплейса, создающего коалиции
покупателей и производителей и моделирующего устойчивость сделки.

## Статус

- Этап 0: создание репозитория и фиксация архитектуры — выполнено.
- Этап 1: границы MVP и пользовательские сценарии — выполнено.

## Документация

Основной план проекта находится в `plan_sborka_b2b.md`.

Результаты этапа 1:

- границы MVP, пути пользователей, список экранов, критерии готовности — `docs/mvp/`;
- сценарий демонстрации, сценарии сбоя, эталонная спецификация, улики — `docs/demo/`;
- синтетические производители, Capability Passport, покупатели — `packages/test-fixtures/`.

## Запуск

Инструкция появится после создания каркаса проекта (этап 2).
