# Фиксированная сборка MinIO

Compose собирает MinIO из официальных исходников, потому что получение ранее указанного образа `minio/minio:RELEASE.2024-12-18T13-15-44Z` в проверенном окружении завершалось ошибкой доступа. Отдельный override и ручная подготовка локального образа больше не нужны.

- Upstream: [minio/minio](https://github.com/minio/minio).
- Коммит: `16f8cf1c52f0a77eeb8f7565aaf7f7df12454583`, соответствует исходному тегу `RELEASE.2024-12-18T13-15-44Z`.
- Архив: `https://codeload.github.com/minio/minio/tar.gz/16f8cf1c52f0a77eeb8f7565aaf7f7df12454583`.
- SHA-256: `7cc89d321b06b265012fa4f49a4b00a715bab5eef3a157c1d348a93ead51d1d2`. Docker проверяет его до распаковки.
- Go 1.23.12, `CGO_ENABLED=0`, `-trimpath`; Alpine 3.20 в конечном образе. Первый запуск требует доступа к исходникам и Go-модулям.
- Версия бинарника обозначена `SOURCE.2024-12-18T13-15-44Z`, с настоящим upstream commit-id. Это сборка проекта, а не официальный release-бинарник. Изменения базовых образов могут менять итоговый digest; идентичность исходников не означает побитовую идентичность контейнера.

AGPLv3 LICENSE находится в `/usr/share/minio/LICENSE`; неизменённый архив соответствующих исходников — в `/usr/share/minio/source.tar.gz`. Его можно получить из своего контейнера:

```bash
docker compose --env-file .env -f infra/docker-compose.yml cp minio:/usr/share/minio/source.tar.gz ./minio-source.tar.gz
```

При распространении контейнера сохранять лицензию и доступ к соответствующим исходникам. Конкретные условия сетевого предоставления и распространения описываются отдельно в [лицензионном реестре](../../docs/legal/license-inventory.md); успешный тест хранилища не является юридическим заключением.

Для другой версии обновлять исходный коммит, контрольную сумму и version metadata согласованно, затем пересобирать и выполнять S3 round-trip и межсервисные тесты. Не подменять источник непроверенным сторонним образом.
