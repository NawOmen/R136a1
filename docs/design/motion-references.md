# Визуальный язык и движение ПоРукам

Публичная главная объясняет связь между офисом покупателя и производством. Каталог и кабинеты остаются рабочими интерфейсами: важны товар, условия и следующее действие. Основа — существующие Manrope, сине-графитовая палитра и объёмная архитектурная сцена. Выдуманные показатели и рекламные обещания не добавляются.

## Принципы

- Один выразительный сюжет вместо одинаковых эффектов на каждом блоке. Зафиксированная сцена меняет состояние; короткая подпись объясняет действие.
- Запрос возникает в офисе, ИИ передаёт требования к производству, стороны согласуют условия, затем партия движется от завода к покупателю. Иллюстрация не выполняет коммерческие действия.
- Заголовок мягко смещается на 3 px и меняет световой акцент в пределах брендовой палитры. Рабочие тексты остаются неподвижными.
- Окно аккаунта располагается поверх всей страницы, удерживает фокус и закрывается клавишей Escape. Фон недоступен до закрытия.
- Пространственное движение отключается при reduced motion и в статичном режиме; анимации останавливаются вне экрана и при скрытой вкладке. На телефоне используется SVG, на поддерживаемом настольном устройстве — Three.js.
- Все представляемые даты используют дд.мм.гг; у событий сохраняется время. ISO остаётся форматом API и значений нативного календаря.

## Панорамная композиция

Главная — единая промышленная сцена: слева маршрут от завода до офиса, справа короткое объяснение текущего этапа на той же тёмной поверхности. На телефоне пояснение переносится под сцену. Заголовок по центру, каталог доступен до прокрутки; создание потребности — после истории. Рабочие страницы сохраняют спокойные поверхности и ясные состояния.

Для формулирования дизайн-задачи использованы принципы [v0 Text Prompting](https://v0.app/docs/text-prompting): задавать конкретные композицию, поведение и ограничения вместо общего «сделай красиво». Применённый бриф: промышленный шоурум, Manrope, сине-графитовая палитра, один главный анимационный сюжет, четыре понятных этапа, минимум текста, без вымышленных коммерческих показателей; мобильная версия и reduced motion обязательны. Код и приватные материалы во внешние генераторы не отправлялись.

## Anime.js, Motion и Kokonut UI

Подключены Anime.js 4.5.0 и Motion 14.4.0 (MIT; Motion поддерживает React 19). Anime.js управляет появлением подписи и заголовка этапа через локальный scope с очисткой. Motion отвечает за появление страницы без дополнительных ключей и размонтирования, перестроение каталога, нажатия, индикатор этапов и пояснения. CSS остаётся владельцем фонового движения сцены; два движка не меняют одно свойство одного элемента одновременно.

Из [Kokonut UI](https://github.com/kokonut-labs/kokonutui) адаптированы `slide-text-button` и `ai-text-loading`: без Tailwind/shadcn и лишних зависимостей. Лицензия сохранена в `apps/web/licenses/Kokonut-UI-MIT.txt`. Загрузка показывает только действительное состояние, без имитации этапов обработки. Reduced motion отключает перемещения и волны. Источники API: [Anime.js React](https://animejs.com/documentation/getting-started/using-with-react/), [Motion React](https://motion.dev/docs/react).
