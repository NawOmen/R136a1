# Обученная модель ПоРукам

Для новых запусков Gateway используется runtime alias `porukam-buyer-qwen3.5`. Он указывает на базу Qwen3.5-9B-4bit и неизменённый LoRA-адаптер SHA256 `b2cf30b111109ee10439b4308cb97058ab00a85115eedd36118bbc534e52b665`. В опубликованном комплекте сохранён прежний артефактный ID `porukam-buyer-b2cf30b11110`, чтобы контрольные суммы Release продолжали сходиться; соответствие зафиксировано в `infra/models.lock.json`.

Адаптер обучался на извлечении фактов из закупочных материалов. Завершённый проход использовал 2160 уникальных синтетических примеров в двух этапах — 1424 и 736 шагов — со сбросом оптимизатора между этапами. Независимая ручная оценка и семантическая приёмка не проводились.

Внутренняя валидация дала 404 из 412 полностью точных ответов: marketplace — 182/184, business — 220/220, авторский набор — 2/8. По фактам micro-F1 составил 99,55%, валидность JSON и точность категории — 100%. Поле `prior_exact` сравнивает результат с предыдущим обученным адаптером, а не с базовой Qwen3.5:9B.

Отдельное парное сравнение на 11 синтетических заявках: обученная модель извлекла всё точно в 11/11 случаев против 5/11 у базовой Qwen3.5:9B; F1 по фактам — 100% против 85,45%. JSON и категория были правильными в 11/11 у обеих моделей. В пяти сквозных сценариях Gateway успешны 2/5 запросов у каждой модели; медианное время составило 22,7 с для обученной модели и 9,7 с для базовой. Малые выборки подтверждают преимущество только на этом тесте извлечения и не показывают роста успешности сквозного сценария.

Незавершённое продолжение обучения не входит в текущие веса. Автономное применение модели не принято. Объяснения и иные задачи вне извлечения фактов отдельно не подтверждены. Локальная конфигурация, ручной запуск и проверенные ограничения описаны в [инструкции развёртывания](../ml-trained-deployment.md).
