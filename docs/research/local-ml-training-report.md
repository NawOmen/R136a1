Автономное применение не принято; автоматического нового обучения нет.

[Манифест модели](ml-current/model.json) и [ручное развёртывание](../ml-trained-deployment.md). Новый Release содержит только адаптер, его конфигурацию, проверяемые контрольные суммы, необходимые сведения о базе, метрики и launcher. Старые Release, учебные корпуса, промежуточные веса и доставочные дубли удалены по прямой просьбе пользователя. Базовые веса и окружение нативного MLX сохраняются для запуска; кэш изображений/речи и чужие рабочие файлы не относятся к этой очистке.

Текстовый Gateway по умолчанию использует MLX с нашим адаптером; скрытого fallback на базовую Qwen нет. Vision остаётся отдельным Ollama-маршрутом. Launcher по умолчанию только проверяет файлы; `--serve` требует явного действия оператора. Развёртывание и merge не выполнялись.

Проверки кода: 35 unit-тестов вне material-workflow прошли с текущей версией модели. Пять аудиотестов на этом Mac ограничены существующим `setrlimit(RLIMIT_AS)`; это не объявляется пройденной проверкой. Живой инференс текущей ветки не запускался. NEXT_STEPS.md не менялся.

Полный восстановленный учебный корпус, исходники и снимок текущего дообучения: [ml/training](../../ml/training/README.md). Веса/checkpoints приложены отдельным комплектом training-* к тому же Release; статус передачи указан в его манифестах.
