# Источники исследования и инструменты для развития ПоРукам

Связанное техническое задание: [конкурс и доработки продукта](contest-expansion-plan.md). Это реестр прочитанных материалов и обоснованных кандидатов, а не обещание подключения всех сервисов. Доступность инструментов проверена в текущей сессии; она не переносится автоматически на другую машину.

## 1. Метод и полнота

Исследование охватывает положение, текущие конкурсные материалы, проблемы B2B-процессов и первичные технические источники по агентам, оценке, локальным моделям, интеграциям и контролю действий. Слова «все статьи» нельзя подтвердить для всего интернета: здесь дан систематизированный корпус релевантных источников, найденные ограничения и направления продолжения. Материалы одного автора или ведомства не считаются независимыми подтверждениями друг друга.

Факт источника, наше проектное решение и гипотеза бизнес-эффекта различаются. Публичные статьи не доказывают спрос именно на ПоРукам. Рекламные цифры не используются для расчёта собственной конверсии, экономии или рынка. Исходные клиентские файлы не отправлялись во внешние инструменты; положение прочитано локально. Команда подтвердила регистрацию в разговоре, письмо-приглашение здесь не проверялось.

## 2. Положение и официальный сайт

**R01.** Предоставленный PDF «Положение RLT. startup.pdf»: 12 страниц; SHA-256 `8ea18fcbf0b9dd51deff95cc32daf129d5f170d1a3779249323ea345f8ddca04`. Проанализирован полный текст; таблица критериев и раскрытие на страницах 10–11 дополнительно просмотрены визуально. Полный PDF в публичный репозиторий не скопирован. Значимые пункты и страницы приведены в основном анализе.

**R02.** [Официальная страница конкурса](https://uni.roseltorg.ru/intensive/rltstart-konkursproektov). Используется прямой адрес без Google-переадресации и рекламных параметров. Первые попытки чтения через веб-инструмент, локальный браузер и HTTP не дали содержимого; Firecrawl вернул ошибку сетевого туннеля. После появления TinyFish выполнена повторная попытка чтения и отдельная браузерная проверка этой страницы. Содержимое официальной страницы получить не удалось. Браузерная задача TinyFish завершена; официальный URL также не загрузился по таймауту. Это ограничение доступности источника в нашем окружении, а не вывод об отмене конкурса. Итог и границы подтверждения записаны в основном анализе. Другие положения Росэлторга о RLT.Hack и чат-ботах исключены: это другие мероприятия.

**R03.** [Анонс Computerra](https://www.computerra.ru/357172/roseltorg-universitet-provodit-konkurs-tehnologicheskih-proektov-rlt-startup/): вторичное описание конкурса. Общая задача автоматизации согласуется с PDF, но публикация не является новым положением и не подтверждает отсутствие иных требований. Поиск TinyFish также вернул анонсы TenChat; они не используются как нормативный источник.

## 5. Источники, не использованные как доказательство

- Поиск нашёл положения о других хакатонах Росэлторга; они исключены независимо от совпадения домена.
- Страница vLLM OpenAI-compatible server вернула перенаправление и затем HTTP 429. vLLM остаётся направлением отдельного сравнения, а не проверенным выбранным runtime.
- Первоначальная страница GenAI OpenTelemetry оказалась перенесённой; использован действующий репозиторий соглашений, а не старый адрес.
- Региональные сообщения о занятости и старые статьи о квотах госзакупок не используются для обобщения на все предприятия РФ.
- Не изучены закрытые кабинеты конкурентов, оплаченные ERP/ЭДО-контракты и реальные клиентские массивы. Их возможности и качество интеграции остаются неизвестными.

| `gh-address-comments`, `gh-fix-ci` | Замечания ревью и сбой GitHub CI | Конкретное исправление причины; в текущем исследовании CI и тесты не запускаются |

Декоративные GSAP, Three.js, shadergradient и glass-навыки не имеют самостоятельного основания в этой функциональной задаче. Их доступность не означает необходимость установки соответствующей библиотеки.

### 6.1. Полезные новые навыки, которые можно создать

Это предложения, пока не установленные и не реализованные:

- `porukam-category-profile`: правила описания категории, единиц, обязательных свойств, допустимых аналогов, производственного процесса и требований документов. Результат — профиль и список вопросов специалисту, без юридического допуска от LLM.
- `porukam-agent-evidence`: проверка полей спецификации/КП по source_refs, состояниям задачи, конфликтам и разрешениям. Результат — подтверждённые поля и объяснение пробелов, без скрытых догадок.
- `porukam-commerce-reconciliation`: сопоставление заказа, приёмки, возврата и затрат с отчётом. Результат — управленческая сверка; не банковская оплата и не бухгалтерское заключение.
- `porukam-integration-contract`: схема импорта/обмена, версии, preview/diff, повтор, разрешения, конфликт и восстановление. Результат — контракт выбранного провайдера, без запросов универсального доступа ко всем данным.

Для каждого: описание триггера, входы, результат, запреты, ошибки, примеры, лицензия ресурсов и версия. Если инструкция должна работать в сайте, её переносит и контролирует runtime проекта; установка в Codex сама по себе этого не делает.

| Инструмент | Фактическая доступность | Зачем нужен | Решение |
| --- | --- | --- | --- |
| GitHub | Каталог подтвердил установленный плагин; для PR доступны и CLI, и инструменты | Чтение исходников, фиксация документации, ревью | Использовать уже доступное; не предоставлять дополнительный доступ без необходимости |
| TinyFish | В начале инструментов не было; позднее появились и принята конкретная задача чтения сайта | Внешние динамические страницы и взаимодействие при исследовании | Не требовать повторного подключения после появления инструментов. Финальный результат чтения сайта указан в основном анализе |
| Firecrawl | Инструменты доступны; вызов официальной страницы завершился ошибкой proxy/tunnel. Каталог отдельно не подтвердил установку | Чтение разрешённых публичных источников | Доступность вызова и успешность чтения — разные факты; не описывать этот вызов как выполненное исследование страницы |
| OpenAI Docs / официальный веб-поиск | Официальные страницы прочитаны | Настройка навыков и протоколов в окружении разработчика | Достаточно текущего доступа; новый платный сервис не требуется |
| Langfuse | Прочитана документация self-hosting; точного соответствующего плагина поиск не подтвердил | Локальная наблюдаемость продукта | Это кандидат runtime/инфраструктуры, а не уже подключённый плагин Codex |
| 1С / Диадок | Прочитаны публичные возможности и документация; учетных данных/коннекторов проекта не проверяли | Каталог, остатки и ЭДО | Отдельные адаптеры после выбора конфигурации, прав и договора; не изображать успешную синхронизацию |

Не подключать всё сразу. Очередность: подтверждённая задача → минимальные разрешения → условия данных/лицензии → контракт → проверяемый результат → эксплуатационная поддержка. Расходы инструмента исследования не являются себестоимостью ИИ-сценария внутри ПоРукам.
