# Восстановление ML-архива

Скачайте ВСЕ porukam-ml-all.tar.partNNN и assets-manifest.json, files-manifest.json, verify_restore.py в одну папку. Python3 стандартной библиотеки достаточен.

Проверка без распаковки: `python3 verify_restore.py`. Проверка и восстановление в новую отсутствующую папку: `python3 verify_restore.py /absolute/new/path`. Проверяются размер/SHA256 каждого тома и каждого файла внутри, запрет абсолютных/родительских путей и симлинков. Тома представляют один tar, порядок по assets-manifest.json.

Окружения и кэши исключены: в архиве сохранены requirements-lock/install reports и лицензии; восстановление окружения выполняется отдельно с проверкой совместимости. Ничего автоматически не устанавливается и обучение не запускается. Не запускайте исторические completed-драйверы повторно в их исходные OUT.

FINAL-TRAINING-STATUS.json фиксирует сохранённую границу512примеров(288+224), optimizer reset и неуспешное завершение нового полного прохода. Последняя пригодная для продолжения точка buyer-prose-recovery-v1/adapter-1856/0000224_adapters.safetensors содержит только веса, без optimizer/RNG. Предыдущий полный2132кандидат сохранён, но REJECT по quality; exact367/412 не является semanticaccuracy.

excluded-files.json перечисляет исключённые среды/кэши/locks/SQL dumps/legacy compressed duplicates. Основные распакованные корпуса и модели сохранены. Закрытые корпуса включены как архивные файлы для сохранности; их нельзя использовать для выбора кандидатов. Данные синтетические. Никаких claims готовности продукта или production promotion.
