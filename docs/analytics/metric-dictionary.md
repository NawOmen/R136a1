# Словарь коммерческих метрик (этап 12)

Определения из NEXT_STEPS.md и их реализация. Деньги считает только обычный код;
LLM результат не считает и не редактирует.

| Показатель | Реализация |
|---|---|
| Заказано | `Deal.units` — согласованное количество (`execution_totals`, `commerce.py`) |
| Куплено / продано | `net_units` = подтверждённая приёмка минус подтверждённые возвраты; отгрузка приёмке не равна |
| Цена сделки | Замороженная смета КП (`frozen_snapshot`, `commercial.py`); текущая цена каталога на прошлое не влияет |
| Средняя цена | `average_prices` в аналитике: сумма исполненного / принятое количество, отдельно по каждой единице; разные единицы не складываются |
| Сумма заказов | Согласованные суммы когорты; отмены и открытые обязательства отдельно; это не полученные деньги (`payments_rub` всегда `null`) |
| Стоимость исполнения | `net_goods_revenue_rub` по снимку с корректировками; доставка — отдельной строкой |
| Получено денег | Не рассчитывается: отдельного подтверждённого платёжного события нет |
| Себестоимость реализованного | `DealCostSnapshot` именно исполненного количества (`unit_cost_rub × net_units`); возвраты корректируют через `net_units` |
| Расчётная валовая прибыль | `revenue − cost` на налоговой базе из карточки затрат (`tax_basis`; `unknown` — сравнение условно) |
| Результат после прямых расходов | `gross − attributable_expenses`; прочие затраты относятся на заказ целиком (см. пояснение отчёта) |
| Чистая прибыль | Не выводится: нет полного состава доходов, расходов и налогов |
| Количество заказов | Уникальные заказы (`orders_count`); строки не увеличивают счётчик; групповые — отдельной группировкой |
| Отказы | `rejection_rate`: отклонено/выбрано/открыто/истекшие; технические сбои — не бизнес-отказ |
| Доля отказов | `rejected / known`, известные исходы указаны явно; нулевой знаменатель — `null` («Нет данных») |
| Отмены / возвраты | События исполнения со статусами запрос/подтверждение/завершение; повтор по ключу не новый исход |
| Физический объём | Только одинаковая единица (`average_prices`, динамика); сводка разных товаров — в рублях и числе заказов |

Когорта: заказы/события по дате создания (UTC, границы включительно); исполнение — текущее
состояние на `built_at`. Групповые обязательства не удваивают оборот: их суммы вне выручки.
