# Optimizer API v1

Базовый локальный адрес: `http://localhost:8004`.

## `POST /api/v1/optimize/allocations`

Принимает требуемый объём, бюджет, срок и список российских производителей с
MOQ, мощностью, ценой, ценовыми ступенями, логистикой и коэффициентом надёжности.
Возвращает три варианта: `cheapest`, `balanced`, `reliable`, распределение по
производителям, итоговую стоимость, срок, объяснение и `input_hash`.

## `POST /api/v1/optimize/coalition`

Проверяет общую производственную основу, жёсткие ограничения, MOQ, мощность,
ценовую ступень, индивидуальные операции, логистику, бюджет, срок и выгоду
каждого покупателя. Невыгодный хотя бы одному участнику вариант получает
`feasible=false`.

## `POST /api/v1/score/opportunity`

Считает `opportunity_score` по зафиксированным весам подтверждённого спроса,
дефицита предложения, Capability Passport, MOQ/мощности, логистики, конкуренции
и качества данных. Расчёт не является прогнозом прибыли.

## `POST /api/v1/optimize/resilience`

Принимает основное распределение, резервные варианты и разрешённые покупателем
пороги цены/срока. Детерминированно строит все N-1 и N-2 сценарии, сохраняя
незатронутые назначения, и возвращает подтверждённое покрытие, вероятное
покрытие, дефицит, изменение цены и срока. Резерв считается подтверждённым
только при действующем согласии производителя и дате удержания мощности.
