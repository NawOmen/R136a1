# LLM Gateway API — этап 4

Базовый URL локально: `http://localhost:8003`. Рабочие методы используют тот же
JWT Bearer, что gateway-auth. Пользовательские сообщения возвращаются на русском.

## Границы безопасности

- Gateway не создаёт предложение, не меняет цену, мощность или статус сделки.
- Создание и публикация потребности остаются отдельными действиями пользователя.
- Оригиналы файлов обрабатываются только локально.
- DeepSeek получает только сокращённый JSON извлечённых фактов без исходного текста.
- JSON модели всегда проверяется Pydantic-схемой.
- Поиск Capability Passport выполняется SQL-кодом, а не LLM.

## Buyer Agent

Расширенные паспорта, справочные цены/сроки и детерминированный краткий итог описаны в [дополнении API v1](capabilities-and-buyer-comparison-v1.md).

`POST /api/v1/buyer-agent/runs` — multipart:

- `request_text` — обычное описание потребности;
- `route` — `local` или `complex_auto`;
- `company_id` — выбранная компания-покупатель; проверяется `can_buy` и исключается из поиска производителей;
- `files` — текст, PDF, изображение или аудио, до 25 МБ каждый и 100 МБ суммарно.

Ответ содержит состояние процесса, восстановленные свойства, источники,
уверенность, конфликты, уточняющие вопросы, найденных производителей и журнал
разрешённых инструментов.

Состояния: `processing_sources`, `extracting_requirements`,
`needs_clarification`, `ready_for_review`, `failed`.

`GET /api/v1/agent-runs/{id}` — получить собственный процесс.

`POST /api/v1/agent-runs/{id}/clarify`:

```json
{
  "answers": {
    "volume_ml": 400,
    "inner_coating": "PE"
  }
}
```

Ответ пользователя записывается как отдельный источник с уверенностью `1.0`.

`POST /api/v1/agent-runs/{id}/confirm` — явное подтверждение восстановленной
спецификации. Метод не создаёт потребность, а только записывает Human Approval;
после него интерфейс переносит значения в обычную редактируемую форму.

## Seller Agent

`POST /api/v1/seller-agent/explain` программно проверяет пересечение запроса с
Capability Passport компании и просит локальную Qwen сформулировать понятное
объяснение. Если модель недоступна, правила продолжают работать и возвращается
`used_route = rules_only`.

## Маршруты моделей

- `local` — только Qwen через Ollama;
- `complex_auto` — для сложного набора из трёх и более источников сначала
  DeepSeek, если настроен ключ; при ошибке или тайм-ауте автоматически Qwen.

`GET /health` не обращается к моделям: отсутствие Ollama или DeepSeek не должно
останавливать базовый маркетплейс.

## S03: версии требований и локальные доказательства (v2)

Новый интерфейс использует `POST /api/v2/buyer-agent/runs` и
`GET /api/v2/agent-runs/{id}`. Формат multipart сохранён; дополнительно возвращается
целочисленная `revision`. Максимум 16 файлов, 25 МБ на файл, 100 МБ суммарно,
PDF до 30 страниц; OCR ограничивает размер растра. Оригинал и локально извлечённый
текст сохраняются в PostgreSQL (`agents.agent_sources`), без внешнего файлового сервиса.
Общий предел текста задаётся `max_combined_text_chars`.

- `POST /api/v2/agent-runs/{id}/clarify`: `answers` и обязательная `expected_revision`.
- `POST /api/v2/agent-runs/{id}/confirm`: обязательная `expected_revision`.
- `GET /api/v2/agent-runs/{id}/sources/{source_id}`: текст, SHA-256 и метаданные;
  `?original=true` скачивает оригинал как attachment. Ответы не кэшируются.
- `POST /api/v2/agent-runs/{id}/sources/{source_id}/invalidate`:
  `expected_revision`; очищает оригинал/текст, сохраняет хеш и историю фактов,
  отменяет связанные подтверждения и увеличивает revision. Удалённый источник — 410.
  Замена материала выполняется новым анализом с новым хешем; прежний материал неизменяем.

Каждый запрос проверяет владельца процесса и актуальное право `can_buy` компании.
Чужой процесс — 404; отозванное право — 403; устаревшая revision — 409;
отсутствующая revision в v2 — 422. V1 сохраняет необязательную revision для прежних клиентов.

Доказательство содержит `original_value`, исходную/нормализованную единицу,
`content_hash`, `extraction_version`, уверенность, цитату и `locator`.
Локатор указывает смещения в сохранённом извлечённом тексте, страницу PDF или
интервал локальной транскрипции; координаты на изображении не придумываются.
Отсутствие точной цитаты оставляет факт предположением до явной проверки человеком.
Подтверждение записывает пользователя и время. `resolved_conflicts` сохраняет
альтернативы, источники, влияние и решение покупателя, привязанное к revision.
Любой оставшийся конфликт/обязательный вопрос блокирует подтверждение.

`POST /api/v1/transcribe` остаётся локальным Whisper-путём с пределом 25 МБ.
Недоступная модель возвращает ошибку, а не успешный пустой результат. Форма хранит
поля в sessionStorage, файлы — в IndexedDB отдельно по пользователю/компании;
503, отказ микрофона и потеря сети оставляют ручной ввод и загрузку файла доступными.
