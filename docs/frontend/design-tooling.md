## Graphify

Официальный пакет [graphifyy](https://github.com/Graphify-Labs/graphify) версии `0.9.56` установлен в отдельное окружение `~/.local/share/codex-tools/graphify` (Apache-2.0 с уведомлениями проекта). Собственный компактный навык `graphify-local` и правила `AGENTS.md` направляют Codex к `scripts/graphify_context.py`. Помощник рассчитан на текущее Linux-окружение и использует `fcntl` для блокировки параллельного обновления.

Помощник сам проверяет индекс при работе с кодом, обновляет его после изменения исходников и запрашивает небольшой фрагмент графа. Пользователю не нужен отдельный промпт. Это обновление по обращению, не постоянно работающий сервис. Граф хранится в игнорируемом `graphify-out/`.

- Только детерминированный AST, без внешней LLM и API-ключей.
- По умолчанию ответ ограничен приблизительным бюджетом 1200 токенов.
- Известные файлы можно читать прямо; граф не заменяет исходники, актуальный план и ревью.
- Документы и изображения не индексируются семантической LLM. Динамические связи могут отсутствовать.
- При отсутствии Graphify на другой машине используется обычный поиск; автоустановка не выполняется. Путь к интерпретатору (`~/.local/share/codex-tools/graphify/bin/python`) в `scripts/graphify_context.py` задан жёстко: если пакета нет, скрипт завершается кодом 2 и просит использовать `rg` и чтение файлов — это ожидаемое поведение, а не ошибка проекта.
- Правила автоматического запуска индекса и делегирования исследования из `AGENTS.md` — предложение автора PR #47. Их стоит утвердить командой отдельно, потому что они меняют процесс работы всех агентов в репозитории, а не только автора изменения.
- Экономия токенов не измерена и не гарантируется для каждой задачи.

## Коннекторы

- **TinyFish:** установлен пользователем. Правила `AGENTS.md` предусматривают автоматический выбор для подходящих задач взаимодействия с внешними сайтами и конкурентного анализа. На 17 сентября установка подтверждена каталогом, но рабочие инструменты не были доступны исследовательской сессии; в таком случае агент сообщает об ограничении и использует доступный веб-поиск. Установка плагина и фактический вызов его инструментов — разные состояния.
- **Firecrawl:** добавлен в личный Codex config, endpoint `https://mcp.firecrawl.dev/v2/mcp`. Проверены MCP initialize и tools/list: доступны `firecrawl_search`, `firecrawl_scrape`, `firecrawl_parse`. Это keyless-режим с лимитами, не полный массовый crawl; доступность инструментов проверяется в текущей сессии. [Официальная инструкция](https://docs.firecrawl.dev/mcp-server/keyless).
- **Perplexity:** не подключён. API-ключ не настроен; встроенный актуальный веб-поиск уже доступен. При необходимости ключ настраивается локально через секреты/переменную окружения, не через чат или Git. [Официальная инструкция](https://docs.perplexity.ai/docs/getting-started/integrations/mcp-server).

Внешним коннекторам не отправляются клиентские файлы, приватный код и ссылки с токенами без отдельного разрешения.

## Code Scout

[Code Scout](https://github.com/di-sukharev/code-scout-skill) установлен в `~/.codex/skills/code-scout` из версии `274dacbfbed872dc08ef20b047f0b5d309d252bd`. Сам навык находится в личном окружении и не включён в этот репозиторий.

- `AGENTS.md` предписывает автоматически применять его, когда задача требует первичного исследования реализации или связей модулей, без отдельного вызова пользователем.
- Исследование поручается одному агенту `gpt-5.6-luna` без истории родителя. Он читает исходники и возвращает компактный отчёт; решения, изменения и проверки остаются за основным агентом.
- Основной агент обновляет Graphify; скаут использует локальный индекс и проверяет выводы по коду. Дополнительные вопросы направляются тому же скауту, чтобы не повторять поиск.
- Для разговора, известного файла или уже достаточного отчёта отдельный запуск не нужен. Если навык или выбранная модель недоступны, используется точечное чтение с явным сообщением об ограничении.
- Делегирование тоже расходует лимит. Количественная экономия не измерена и не гарантируется для каждой задачи.
