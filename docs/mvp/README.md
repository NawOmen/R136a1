# Этап 1 — Границы MVP и пользовательские сценарии

Материалы этого каталога фиксируют границы MVP, пути пользователей и критерии готовности прототипа. Пользователь работает через единый аккаунт и одну компанию, может одновременно иметь разрешения `buyer` и `seller` и переключаться между режимами «Покупаю / Продаю».

| Документ | Содержание |
| --- | --- |
| `01-mvp-boundaries.md` | Единственная товарная категория, границы «входит / не входит», снятие спорных требований |
| `02-buyer-journey.md` | Путь покупателя (Buyer Journey) |
| `03-seller-journey.md` | Путь производителя (Seller Journey) |
| `04-admin-demo.md` | Администраторская демонстрация |
| `05-screens.md` | Утверждённый список экранов |
| `06-prototype-ready-criteria.md` | Критерии «прототип готов» |
