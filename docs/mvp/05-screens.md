# Утверждённый список экранов

Версия: 1.0 · Дата: 28 августа 2026 · Статус: утверждено

Правила UX: один экран — одно основное решение; максимум три основных действия; обычный русский язык; значения можно исправить вручную; последствия объясняются до подтверждения; критичные изменения требуют явного подтверждения.

## Общие

1. Вход / регистрация
2. Выбор роли (после входа, если ролей несколько)
