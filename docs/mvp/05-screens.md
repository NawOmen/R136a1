# Утверждённый список экранов

Версия: 1.2 · Дата: 27 августа 2026 · Статус: утверждено (обновлено под план v1.6)

Правила UX: один экран — одно основное решение; максимум три основных действия; обычный русский язык; значения можно исправить вручную; последствия объясняются до подтверждения; критичные изменения требуют явного подтверждения.

## Общие

1. Вход / регистрация единого аккаунта (ФИО, email, пароль, необязательный телефон)
2. Профиль и статус проверки компании; включение разрешений `buyer`/`seller`; переключатель «Покупаю / Продаю»
