# Документация ПоРукам

**Продолжать работу с [NEXT_STEPS.md](../NEXT_STEPS.md).** Это единственный актуальный план оставшихся задач: этапы 00–19, база реализации, все бизнес-проблемы/категории, денежные и ресурсные правила, аналитика, пять критериев и подача. Прежние W01–W33/C01–C28/T01–T46 сохранены в карте переноса. Статусы меняются в том же файле; отдельный TODO/журнал не нужен.

[AGENTS.md](../AGENTS.md) и [SKILL.md](../SKILL.md) задают рабочие правила, [спецификация](../plan_sborka_b2b.md) — предметные требования/дизайн, [положение](../Положение%20RLT.StartUp.md) — первичные нормы. [Единый отчёт проверки](reviews/verification-baseline.md) сохраняет выполненные проверки и происхождение изменений; он не подтверждает все цели продукта.

## Запуск и размещение

Приложение запускается через Docker: [быстрый старт](../README.md),
[сервер и два ноутбука с ИИ](../DEPLOYMENT.md). Инструкция включает требования
к связи, RTX/MacBook, HTTPS, ручной выбор, автоматический резерв и распределение.

## Сохранённые источники и рабочие материалы

| Раздел | Назначение |
|---|---|
| `api/` | Версионированные контракты фактических интерфейсов |
| `architecture/` | Технические решения, схемы, ограничения и реальные связи; завершение по NEXT_STEPS |
| `demo/` | Воспроизводимые инструкции/исторические синтетические сценарии, не ограничение аудитории |
| `contest/` | Пять приложений, существующий PPTX и сценарий технического показа; актуальность проверяется перед подачей |
| `analysis/` | Внутренний анализ S16, версионированные сценарные расчёты и все категории; статусы только в NEXT_STEPS |
| `research/` | Исследования/первоисточники и реестр ИИ-инструментов; исторические оценки не новый статус кода |
| `legal/` | Матрица применимости, лицензии и проекты документов; не действующие соглашения без утверждения |
| `security/` | Инструкции защищённого запуска и исторические основания исправлений |
| `frontend/` | Сохранённая концепция интерфейса, навыки и версии источников |
| `reviews/verification-baseline.md` | Один отчёт с результатами, пределами и безопасным повторением |
| `../packages/test-fixtures/` | Машиночитаемые синтетические данные и Markdown-входы; удалять как выполненные планы нельзя |

Устаревшие планы и промежуточные отчёты удалены после переноса требований/доказательств; их полные версии доступны в Git. Этот каталог содержит контракты, артефакты и инструкции, а не дополнительные очереди задач.
