# Этап 8: прогон конкурсного прототипа

## Запуск в локальной сети

1. Узнать адрес компьютера в сети: `hostname -I` (Linux) или `ipconfig getifaddr en0` (macOS).
2. В `infra/.env` задать `CORS_ORIGINS=http://localhost:3000,http://<IP>:3000`.
3. Выполнить `docker compose -f infra/docker-compose.yml up -d --build`.
4. На втором устройстве открыть `http://<IP>:3000`. Клиент автоматически обращается к API на том же IP и портах 8001–8003.
5. Не выставлять эти порты в интернет; режим рассчитан на доверенную локальную сеть.

## Офлайн-режим

До защиты один раз собрать и получить все образы и локальную модель. Затем отключить сеть и выполнить:

`docker compose -f infra/docker-compose.yml -f infra/docker-compose.offline.yml up -d`

Проверить `/health` у портов 8001–8004 и открыть главную страницу. Облачный DeepSeek без ключа не используется; основная модель берётся из локального Ollama согласно `infra/models.lock.json`.

## Пять полных репетиций

Каждый прогон: публичная главная → регистрация → компания → карточка товара с фото и двумя ценовыми ступенями → публикация → карточка потребности → подбор → подтверждение → поддержка/администратор. Фиксировать результат в таблице ниже, не отмечая непройденный прогон как успешный.
