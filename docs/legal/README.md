# Правовые материалы прототипа

> **Проектный материал. Не является юридической консультацией и не утверждён для публичного использования.**

Документы в этой папке описывают предполагаемую модель российского B2B-маркетплейса «Сборка B2B». До публичного запуска их должен проверить профильный российский юрист с учётом фактического оператора, способов оплаты, аналитики, cookies и договорной схемы.

В прототипе используются только синтетические компании, реквизиты и обращения. Формы должны собирать только необходимые данные; срок хранения, основание и способ удаления перечислены в [матрице применимости](compliance-matrix.md).

Черновики:

- [пользовательское соглашение](draft-user-agreement.md);
- [политика персональных данных](draft-personal-data-policy.md);
- [согласия и cookie-уведомление](draft-consents-and-cookie.md);
- [правила покупателей и производителей](draft-marketplace-rules.md);
- [поддержка и ИИ-функции](draft-support-and-ai-terms.md).

Контроль перед публикацией: назначить оператора и ответственного, заполнить реквизиты и каналы связи, провести правовую экспертизу, утвердить версии и даты, реализовать журнал согласий и проверенный процесс удаления данных.
