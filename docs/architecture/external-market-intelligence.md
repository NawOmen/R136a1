# Безопасная внешняя рыночная разведка

Статус: проектирование, не реализация этапа 7.

Разрешены только официальные API, открытые государственные данные, публичные сайты с явно допустимым автоматизированным доступом и данные, предоставленные правообладателем. Для каждого источника ведётся реестр: владелец, URL/API, условия, правовое основание, лимит, дата проверки, разрешённые поля и срок хранения.

Запрещены обход CAPTCHA/авторизации/robots и технической защиты, маскировка бота, сбор персональных контактов, автоматические сообщения продавцам и публикация чужих карточек. Агент может сформировать черновик предложения и ссылку, но отправка возможна только человеком через разрешённый канал.

Контур: allowlist источников → ограниченный загрузчик → проверка лицензии и персональных данных → нормализация → карантин недоверенного текста → сопоставление без изменения сделок → объяснение пользователю → Human Approval. При запрете, неоднозначных условиях или блокировке источник отключается без попытки обхода.
