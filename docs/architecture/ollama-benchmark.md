# Проверка локальной LLM — Qwen3.5 9B (Ollama)

Дата: 27 августа 2026.

> Измерения ниже выполнены на **рабочей машине разработчика (macOS, Apple Silicon)**,
> где запущена Ollama. Это не «основной компьютер» конкурса (Intel Core Ultra 7 255H + RTX 5060 8 ГБ).
> Показатели RAM/VRAM для основного компьютера нужно замерить на нём самом — команды и таблица приведены в конце.

## Модель

- имя в Ollama: `qwen3.5:9b`;
- формат: GGUF, квантизация Q4_K_M;
- параметры: 9.7B;
- возможности: vision, completion, tools, thinking;
- загруженный в память объём (`ollama ps`): 5 498 564 770 байт ≈ **5,5 ГБ** (`size_vram` совпадает — на Apple Silicon используется unified memory);
- фактически загруженное контекстное окно (`ollama ps`): **4 096 токенов** (заявлено 262 144, в прототипе начинаем с 8 192 после замера).

## Замер генерации

Тестовый запрос: «Одним предложением ответь: что такое одноразовый бумажный стакан для горячих напитков?»

| Метрика | Значение |
| --- | --- |
| Скорость генерации (по `eval_duration`) | ~21 ток/с |
| TTFT, холодный запуск (загрузка модели + thinking) | ~63,8 с |
| TTFT, прогретый запуск (thinking) | ~53,8 с |
| Сгенерировано токенов (`eval_count`) | 1 247–1 335 |

Ответ модели:

> Одноразовый бумажный стакан для горячих напитков — это многослойная ёмкость из картона с термостойким покрытием, предназначенная для однократной подачи кофе или чая и последующего выбрасывания.

Примечание: Qwen3.5 9B по умолчанию использует thinking (цепочку рассуждений), поэтому TTFT включает время thinking. Сырая скорость генерации по `eval_duration` ≈ 21 ток/с.

## Замер RAM и VRAM на основном компьютере (Linux + RTX 5060)

Значения ниже **не придуманы** — их нужно замерить на основном компьютере командами:

```bash
# до загрузки модели
nvidia-smi --query-gpu=memory.used,memory.total --format=csv,noheader
free -h

# во время генерации (в параллельном терминале)
nvidia-smi --query-gpu=memory.used,memory.total --format=csv,noheader
free -h
ollama ps
```

Таблица для заполнения:

| Показатель | Значение |
| --- | --- |
| Использованное контекстное окно | заполнить |
| RAM до загрузки модели | заполнить |
| RAM во время генерации | заполнить |
| Пиковое потребление RAM | заполнить |
| VRAM до загрузки модели | заполнить |
| VRAM во время генерации | заполнить |
| Пиковое потребление VRAM | заполнить |
| Время холодного запуска | заполнить |
| Результат прогретого запуска | заполнить |
| Скорость токенов в секунду | заполнить |
| TTFT | заполнить |

Полный скрипт проверки: `infra/verify_ollama.py`.
