# Архитектура этапа 4: восстановление требований и агенты

## Поток покупателя

1. Пользователь вводит русское описание и выбирает фото, PDF, текст или аудио.
2. PDF-текст извлекается локально; скан и фото распознаёт локальная Qwen Vision;
   аудио расшифровывает локальный faster-whisper (`small`, русский язык).
3. Buyer Investigation Agent получает недоверенные текстовые источники и
   возвращает факты только по JSON Schema.
4. Обычный код группирует факты, обнаруживает разные значения одного свойства,
   рассчитывает статус и формирует не более трёх уточняющих вопросов.
5. Marketplace Agent программно ищет проверенные российские компании по
   Capability Passport — наличие точной карточки товара не обязательно.
6. Пользователь видит группы «Подтверждено», «Предполагается», «Нужно уточнить»
   и вручную переносит результат в обычную форму.
7. Только Marketplace Service сохраняет черновик и публикует его после
   отдельного подтверждения.

## Доказательства

Каждое свойство содержит канонический ключ, русскую подпись, значение, список
источников с выдержкой, уверенность `0..1` и статус `confirmed`, `assumed` или
`needs_clarification`.

Противоречия ищутся детерминированно: разные нормализованные значения одного
ключа нельзя автоматически превратить в подтверждённое требование.

## Разрешённые инструменты

Buyer Agent может вызвать только локальное извлечение материала, извлечение
структуры и read-only поиск Capability Passport. Seller Agent использует
read-only паспорт и LLM-объяснение. Каждый вызов сохраняется в `agents.tool_calls`.

Ни один агент не имеет инструмента изменения цены, мощности, предложения,
резерва или сделки.

## Внешний маршрут

DeepSeek необязателен. Оригинальные файлы и распознанный полный текст всегда
остаются в локальном маршруте. Внешнему консультанту передаётся только сокращённый
JSON уже извлечённых фактов без цитат и идентификаторов компаний, дополнительно
обработанный обезличиванием. Его ответ может добавить замечания, но не заменить
значения. Ошибка, тайм-аут или неверный JSON переключает проверку на Qwen. Если
локальная модель недоступна, запуск завершается контролируемым `503`, не изменяя
данные маркетплейса.

## Сравнение моделей

`python infra/compare_llm_routes.py` запускает обе модели на трёх одинаковых
синтетических задачах. Без `DEEPSEEK_API_KEY` выполняется только Qwen; результаты
в репозитории заранее не выдумываются.
