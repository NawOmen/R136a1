# Тестовые данные (fixtures) этапа 1

Версия: 1.1 · Дата: 26 августа 2026 · Статус: утверждено (обновлено под план v1.5)

Синтетические данные для разработки и демонстрации. Все компании, реквизиты, документы и контакты вымышленные.

| Каталог | Содержание |
| --- | --- |
| `manufacturers/manufacturers.json` | 11 синтетических производителей (полные записи) |
| `capability-passports/` | Capability Passport каждого производителя (`mfr-001.json` … `mfr-011.json`) |
| `buyers/buyers.json` | Запросы четырёх покупателей (основной, совместимый, малый ниже MOQ, партнёр по объединению) |
| `need-cards/need-cards.json` | Подтверждённые карточки потребностей со статусами, видимостью и причинами отсутствия подбора |
| `demand-pooling/demand-pooling.json` | Профили совместимости и групповое предложение (5 000 + 45 000 → 50 000) |
| `market-opportunities/market-opportunities.json` | Сигналы спроса/предложения и пример рекомендации «Что сейчас нужно рынку» |
| `buyer-evidence/` | Комплект «улик» покупателя: фото, ТЗ, накладная, голос |
| `agent-task-bank/` | Банк русскоязычных агентных задач S04: корректные/конфликтные входы и эталонные критичные поля |
| `reference-specification.json` | Эталонная спецификация (ground truth) |

Соглашение об именах:

- производители: `mfr-001` … `mfr-011`;
- покупатели: `buyer-001` … `buyer-004`;
- карточки потребностей: `need-001` … `need-004`;
- профили совместимости: `cp-001`, `cp-002`; групповое предложение: `go-001`;
- эталонная спецификация: `ref-spec-001`.
