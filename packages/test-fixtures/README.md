# Тестовые данные (fixtures) этапа 1

Версия: 1.0 · Дата: 28 августа 2026 · Статус: утверждено

Синтетические данные для разработки и демонстрации. Все компании, реквизиты, документы и контакты вымышленные.

| Каталог | Содержание |
| --- | --- |
| `manufacturers/manufacturers.json` | 10 синтетических производителей (полные записи) |
| `capability-passports/` | Capability Passport каждого производителя (`mfr-001.json` … `mfr-010.json`) |
| `buyers/buyers.json` | Запросы двух покупателей (основной и совместимый) |
| `buyer-evidence/` | Комплект «улик» покупателя: фото, ТЗ, накладная, голос |
| `reference-specification.json` | Эталонная спецификация (ground truth) |

Соглашение об именах: идентификаторы производителей — `mfr-001` … `mfr-010`, покупателей — `buyer-001`, `buyer-002`, эталонной спецификации — `ref-spec-001`.
