# Комплект «улик» покупателя

Материалы, которые покупатель загружает одной операцией в сценарии демонстрации.

- `photo/sample-cup.png` — синтетическое PNG-изображение образца;
- `photo/photo-description.md` — текстовое описание того, что видно на фотографии;
- `tz-technical-specification.md` — русскоязычное техническое задание;
- `nakladnaya-previous-supplier.md` — старая накладная прошлого поставщика;
- `voice-message.m4a` — аудиозапись голосового сообщения (синтетическая, озвучена TTS);
- `voice-message-transcript.md` — расшифровка того же голосового сообщения.

Ключевые противоречия, которые должен обнаружить агент:

1. объём: 400 мл (ТЗ) против 350 мл (накладная);
2. покрытие: PE (ТЗ) против PLA (накладная).

Правильные ответы покупателя: 400 мл, PE.
