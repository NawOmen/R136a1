# Описание фотографии образца

Файл: `sample-cup.svg` (макет-заглушка; реальная фотография будет добавлена перед этапом 4).

Что видно на фотографии:

- одиночный бумажный стакан для горячих напитков, вид спереди, нейтральный фон;
- корпус крафтового (коричневого) цвета;
- белый ободок сверху;
- по центру — белый логотип: круг с надписью «LOGO»;
- в нижней части корпуса частично видна маркировка «400 ml»;
- крышка отсутствует.

Что должно извлечь зрение модели (ожидаемые визуальные признаки):

- класс: бумажный стакан (одноразовая посуда);
- цвет корпуса: крафтовый;
- наличие печати/логотипа: есть, белого цвета;
- маркировка объёма: «400 ml» (частично читаемая);
- точный материал и тип покрытия по фото не определяются (гипотеза, а не подтверждение).
