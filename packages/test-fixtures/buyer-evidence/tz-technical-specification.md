# Техническое задание

**На поставку одноразовых бумажных стаканов для горячих напитков**

Заказчик: ООО «Кофейный дом “Рассвет”» (г. Москва)

## 1. Наименование товара

Стакан бумажный одноразовый для горячих напитков.

## 2. Характеристики

| Параметр | Значение |
| --- | --- |
| Объём | 400 мл |
| Материал корпуса | крафт-картон, 300 г/м² |
| Внутреннее покрытие | пищевое PE-покрытие (полиэтилен), ~15 г/м² |
| Печать | полноцветная (CMYK), логотип по макету, 4+0 |
| Диаметр верха | ~90 мм |
| Диаметр дна | ~60 мм |
| Высота | ~130 мм |

## 3. Количество и упаковка

- Количество: 120 000 (сто двадцать тысяч) штук.
- Упаковка: гофрокороба по 500 штук.

## 4. Требования

- Товар должен соответствовать ТР ТС 005/2011 (упаковка, контактирующая с пищевой продукцией).
- Материал должен быть разрешён для контакта с горячими напитками.
- Печать — стойкая к истиранию, без запаха.

## 5. Срок и место поставки

- Срок: 10 (десять) календарных дней с момента подтверждения заказа.
- Место поставки: г. Москва.

## 6. Бюджет

- Не более 1 900 000 (одного миллиона девятисот тысяч) рублей.

Составил: менеджер по закупкам ООО «Кофейный дом “Рассвет”».
