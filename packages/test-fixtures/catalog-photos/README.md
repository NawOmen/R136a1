# Фотографии локального каталога

33 отдельных изображений созданы встроенным ImageGen по запросам из `prompts.json`.
Это синтетические студийные иллюстрации товаров, а не фотографии реальных партий
или документальное подтверждение характеристик. Чужие фото и бренды не использованы.
Каждый файл соответствует одному SKU; варианты стаканов имеют отдельные изображения.

Исходные PNG преобразованы в WebP (до 1024×1024, качество 86) существующим Sharp,
без изменения содержания. Промпты сохранены для воспроизводимого визуального стиля.
Загрузка и ограничения описаны в корневом README. Производственные зависимости
для подготовки или показа этих файлов не добавлены.
