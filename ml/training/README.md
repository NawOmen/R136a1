# Данные и исходники обучения ПоРукам

Полный восстановленный учебный корпус — [buyer-restored-fullpass-20261023/train.jsonl](buyer-restored-fullpass-20261023/train.jsonl): 2132 синтетических примера, 1472 маркетплейса и 660 коммерческих. Проверочный корпус — соседний valid.jsonl, 588 примеров. Проверочные примеры не используются для обучения. 28 прозаических примеров старого корпуса не восстановлены; комплект не объявляется точной копией старых 2160 строк.

Продолжение использует [buyer-restored-continuation-20261023/train.jsonl](buyer-restored-continuation-20261023/train.jsonl): 676 оставшихся строк исходного расписания после сохранённых 1456. Порядок и привязка ID находятся в schedule.json; параметры и сброс оптимизатора описаны в preparation.json. Шаги выданного iterator не равны завершённым шагам.

Это снимок активного обучения; момент и SHA256 всех файлов — training-files.json. Скрипты, настройки, метрики, ошибки, лицензии и сведения о базе включены. Ненужные сведения о чужих локальных процессах удалены; исходные и экспортированные SHA указаны отдельно. Зависимости, кэши, блокировки и закрытые test не включены.

Все сохранённые веса/checkpoints передаются отдельными assets training-* в [том же единственном Release](https://github.com/NawOmen/R136a1/releases/tag/ml-trained-current-20261022); код и данные доступны прямо в PR. training-files.json перечисляет содержимое архива. Пока загрузка не проверена, это не подтверждение её завершения.

Для восстановления скачать training-assets.json и перечисленные им части, проверить размер/SHA каждой, соединить части по порядку манифеста и распаковать tar.gz в отдельный каталог. Проверить каждый файл по training-files.json. Базовые веса отдельно: mlx-community/Qwen3.5-9B-4bit, ревизия из porukam-trained-current/base-download-manifest.json; окружение — из pip-freeze.txt. Ничего не скачивается и не запускается автоматически.

Скрипты сохраняют исторические пути и защищают старые выходные каталоги от повторного запуска. Для нового эксперимента нужен отдельный OUT и явный путь к локальной базе/адаптеру; не запускать старый session-v1/v2 поверх архива. Текущая опубликованная модель остаётся неизменной; новые веса не прошли оценку качества. Развёртывание и merge не выполняются.
